## 💼 Что я сделал на работе

> Коммерческий код закрыт, поэтому коротко.

- **Надёжная доставка документов.** Спроектировал и написал с нуля три микросервиса на Python: Kafka → Transactional Outbox (PostgreSQL) → RabbitMQ → Inbox (FastAPI) → Odoo. Доставка at-least-once, идемпотентный приём, дедупликация, повторы с экспоненциальной задержкой и jitter, DLQ, проверки работоспособности и watchdog'и.
- **Обработка текста вне монолита.** Вынес нормализацию документов из Odoo в асинхронный сервис: очистка HTML, определение языка и тональности, ключевые слова, сопоставление полей для Telegram, Twitter, LinkedIn и других площадок.
- **Celery внутри Odoo 17.** Внедрил Celery с RabbitMQ, Redis и Flower: приоритетные очереди, DLQ и политики повторов для тяжёлых операций.
- **Формы сбора данных.** Основной разработчик модуля форм на базе Odoo Survey: новые типы вопросов, редактируемые таблицы-матрицы, разграничение доступа, экспорт в XLSX и печать.
- **Отчёты с LLM.** Встраиваемые в отчёты ленты документов, переработка текста через GigaChat и LangChain, собственный конвертер HTML → DOCX.
- **Клинические исследования (CTMS).** Редактирование заполненных eCRF с историей «было → стало», автоматическая смена статусов, журнал аудита для 21 модели, выгрузка 110 тыс. ответов в Excel меньше чем за 6 секунд.
